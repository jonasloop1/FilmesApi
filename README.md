## 🎬API de Gerenciamento de Filmes
 
Uma API REST desenvolvida para facilitar o gerenciamento de uma coleção de filmes, permitindo que usuários organizem seus títulos favoritos ou criem listas personalizadas de acordo com suas preferências.

Funcionalidades:

📌 Cadastrar novos filmes.
🎥 Listar todos os filmes cadastrados.
🔍 Buscar um filme por ID.
✏️ Atualizar as informações de um filme.
🗑️ Remover filmes da coleção.
✅ API REST com operações CRUD completas.
